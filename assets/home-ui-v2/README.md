## 提示词摘要

统一风格：厚深蓝描边、鲜明大色块、简化为两到三层的明暗、夸张比例、左上光照、减少写实材质纹理和细碎反光。每张图标独立生成，透明背景、无文字、无底板。

- 背景：沿用 V1 基地与远方遗迹构图，简化木纹、书架藏品和地面碎石，改为粗壮建筑和大石板；中央开放宝箱使用夸张锁扣和少量大金币、宝石。保留暖色室内与蓝紫色远景，右侧留较暗区域，无人物和 UI。
- 蓝色底板：正面圆角切角方形，宝蓝色面、浅蓝上斜面、深蓝下斜面、粗轮廓和短硬阴影，内部空白。
- 黄色底板：约 2.8:1 横向按钮，黄色面、浅黄上沿、橙色下沿，去除地图花纹，内部空白。
- 仓库：矮胖木箱、大金属锁扣、宽金箍、三块大木板，无木纹。
- 图鉴：厚封面、简化书页、右页巨大金色四角星，左页空白。
- 收藏馆：宽杯身、夸张粗把手、短杯柱和方底座，正面大星形装饰。
- 指南针：宽金圆框、蓝色表盘、大红白指针，只留四个方向标记，去除细刻度与玻璃反光。
- 金币：单枚厚金币、中央巨大四角星、黄色和橙色色块、粗描边，减少渐变与金属反射。
