# 理包模拟器仓库交互参考

来源：https://df.lza11111.com/game 。下载日期：2026-10-13。

本目录保存公开HTML、前端入口与动态脚本、入口CSS，用于静态阅读；不是完整网站备份，不包含服务器、账号数据或全部图片。未执行下载的脚本。核心部分通过WebAssembly调用，当前没有下载或分析该二进制。因此以下区分已确认的前端行为与未确认的核心规则。

## 可确认的实现

- BdaFfQiT.js：桌面网格注册cellSize为56，网格尺寸为列数×56+1、排数×56+1。每件物品根据position.x/y定位，按矩形宽高占格。物品图像在矩形内缩至约90%，描边与底色用于区域辨识。
- D64SpAGJ.js：指针相对容器坐标除以格子尺寸，计算整数落点。kn函数以拖动物品尺寸修正中心对齐，避免仅按光标所在格直接放左上角。
- D64SpAGJ.js：拖动预览返回highlight矩形、valid状态、rotated状态；预览边界裁切到容器内。提交前重新计算目标，调用endDrag处理；具体失败或交换规则在外部核心，不能仅凭该调用断言。
- BDUEa-bw.js：独立拖动图像预览使用translate3d，宽高按占格尺寸计算，指针位于预览中心，带阴影。
- Mv9Uo35b.js：物品含instanceId及独立旋转状态；非正方形拖动物品可以旋转。
- D64SpAGJ.js：拖动时R切换旋转，Esc取消。支持有效目标时自动旋转的状态更新。
- CVV4VjW0.js：尺寸函数在旋转时交换length/width。部分核心逻辑调用WASM，包括有效尺寸、容器用量等。

## 对本项目的建议

保留既定的深蓝背景、白色半透明网格和极简导航。下一轮可优先补落点矩形预览及有效/无效颜色、拖动中Esc取消、非正方形物品R旋转，以及边缘自动滚动。当前已有矩形占格、独立物品、移动碰撞验证及位置保存。上述新增功能仅是从参考提炼的建议，尚未自动修改本项目。
