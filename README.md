# Wonderseeker · 异想寻宝家

单机网页开箱与收藏游戏。开启不同等级的容器，发现藏品、整理仓库，并把心爱的收藏摆进展馆。

**[在线游玩](https://wonderseeker.yjyj200410.chatgpt.site)** · [运行与开发说明](game/README.md)

## 当前内容

- 7 种容器：下水道、街角木箱、旧城铁箱、秘境匣子、失落宝箱、皇室珍藏、星界遗物。
- 42 种藏品：41 种普通藏品和 1 种 EX「无尽之心」，包含中国主题与世界藏品。
- 逐件揭晓、稀有物品演出、音效与背景音乐。
- 格子仓库、拖动与旋转、一键整理、锁定、批量出售及自动出售。
- 翻页图鉴、发现记录，以及 6 个收藏馆展位。
- 浏览器本地存档、导入导出与离线资源缓存，支持桌面和手机布局。

游戏无需账号，使用虚拟游戏币，无充值或真实货币交易。存档保存在当前浏览器，不自动跨设备同步；更换网址或浏览器前请先导出存档。

## 本地运行

安装 Node.js 后，在项目根目录执行（无需安装 npm 依赖）：

```sh
cd game
npm run dev
```

打开 `http://127.0.0.1:4173`。在 `game` 目录运行测试：

```sh
npm test
```
