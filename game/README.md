# Wonderseeker · 异想寻宝家

简单多边形画风的单机网页收藏游戏，MVP 0.1。

## 本地运行

需要 Node.js，不需要安装 npm 依赖。

```powershell
cd C:\Users\test123\Desktop\Reta\game
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。可用 `node server.mjs 4174` 指定其他端口。端口或网站地址变化会使用不同的浏览器存档；迁移进度请导出再导入。

```powershell
npm test
```

## 工程结构

- `dist/`：直接部署的静态应用与源文件，无打包步骤。
- `dist/engine.js`：纯游戏规则与存档校验，和界面分离。
- `dist/content.js`：命名、多边形 SVG 与箱子素材。
- `dist/storage.js`：IndexedDB 读写；仅事务提交后更新内存状态。
- `dist/app.js`、`dist/style.css`：页面与交互。
- `dist/assets/home-ui/`：主页 V2 贴图的部署副本，来源为项目 `assets/home-ui-v2/`。
- `dist/economy.json`：`docs/GAME_ECONOMY_V2.json` 的部署副本；V1 配置保留为历史记录。
- `tests/engine.test.mjs`：15 项行为与边界测试。
- `.openai/hosting.json`：Sites 身份与静态目录。

采用原生 JavaScript ES Modules、HTML/CSS/SVG，使首版无需框架依赖即可运行。金额以十进制字符串持久化、BigInt 计算，等级概率使用无偏 48 位整数采样。

修改经济配置时，同步部署副本并执行规则及经济验证；修改静态资源时更新 `sw.js` 的缓存版本。没有存档迁移方案前，不更改已有 schema/economy/content 版本含义。

## 浏览器要求与范围

使用支持 IndexedDB、Web Locks、BigInt 和 Service Worker 的现代浏览器。运行于 HTTPS 或 localhost；请通过 HTTP 服务打开，不直接双击 HTML。

首次加载联网，缓存完成后可断网重开。存档只属于当前浏览器和网站地址，不自动跨设备同步；清除网站数据会清除进度。导出的备份允许恢复到历史状态，单机版不做防修改或防回档承诺。

正式长期节奏和真实移动设备仍需持续试玩。本版不含 3D、账号、服务器、交易、排行榜或真实货币系统。
