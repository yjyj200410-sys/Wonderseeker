# Wonderseeker · 异想寻宝家

原生 JavaScript 单机网页收藏游戏，当前包版本为 `0.1.0`。

**[在线游玩](https://wonderseeker.yjyj200410.chatgpt.site)**

本文描述当前仓库实现；线上版本独立部署，不会随 GitHub 提交自动更新。

## 本地运行与验证

需要 Node.js，无需安装 npm 依赖。从项目根目录运行：

```sh
cd game
npm run dev
```

打开 `http://127.0.0.1:4173`。如需其他端口，在 `game` 目录执行 `node server.mjs 4174`。

在 `game` 目录运行现有测试与经济校验：

```sh
npm test
node ../docs/verify_economy_v2.mjs
```

请通过本地 HTTP 服务运行，不要直接双击 HTML 文件。

## 当前玩法与内容

- **寻宝与成长**：7 种容器，经验解锁、成长奖励和 V2 开箱经济配置。
- **藏品**：普通 1～7 级共 41 种，加上 EX「无尽之心」，图鉴共 42 项；包含中国主题和世界藏品，使用独立物品贴图。
- **揭晓演出**：逐件点击揭晓，可跳过至总览；7 级与 EX 使用分阶段演出，配合品质光效、背景音乐和音效，支持减少动画设置。
- **格子仓库**：每件藏品独立占格，20 列、至少 10 排，行数随摆放扩展；支持鼠标或触摸拖动、旋转、落点预览和一键整理。
- **出售与保护**：逐件选择、按品质批选、确认出售、锁定保护；自动出售仅处理严格低于设置价值阈值的新掉落，发现记录仍保留。
- **图鉴与收藏馆**：书本翻页图鉴、历史发现和物品详情；6 个展位，可选择、替换与撤下藏品。
- **界面与设置**：中文界面、桌面和手机布局、音效设置、全屏及存档导入导出。

## 存档与浏览器

存档使用 IndexedDB，并提供待处理结果恢复和单标签写入保护。请使用支持 IndexedDB、Web Locks、BigInt 和 Service Worker 的现代浏览器。

存档属于当前浏览器和网站来源；更换域名、端口或浏览器会使用另一份存档。旧地址中的进度不会自动迁移到新地址，迁移前请在旧地址导出，再到新地址导入。清除网站数据会清除本地进度，建议定期导出备份。

首次加载需要联网；在 HTTPS 或 localhost 下完成 Service Worker 资源缓存后，可离线重开。游戏不含账号系统、云存档、交易、排行榜或真实货币系统。

## 工程结构

| 路径 | 用途 |
| --- | --- |
| `dist/` | 静态应用与浏览器源文件，可直接部署，无打包步骤 |
| `dist/app.js`、`dist/style.css` | 页面与交互 |
| `dist/content.js`、`dist/world-items.js` | 藏品目录、容器与素材映射 |
| `dist/engine.js` | 游戏规则、经济计算、存档校验与旧内容迁移 |
| `dist/storage.js` | IndexedDB 存档读写 |
| `dist/warehouse.js` | 仓库布局、移动、整理与出售 |
| `dist/special-reveal.js`、`dist/special-reveal.css` | 稀有藏品分阶段演出 |
| `dist/economy.json` | V2 经济配置的部署副本 |
| `dist/assets/` | 游戏运行所用图片与音频 |
| `dist/sw.js` | 离线缓存与缓存版本管理 |
| `tests/` | 规则、藏品、仓库、音频与揭晓等测试 |
| `server.mjs` | 本地静态文件服务器 |
| `.openai/hosting.json` | 现有 Sites 项目标识与静态目录配置 |

## 部署与维护

部署静态目录 `game/dist/`，通过 HTTPS 提供访问。`server.mjs` 仅用于本地预览，无需作为线上后端部署。当前在线网址由 Sites 托管，GitHub 仓库用于保存与分享项目代码。

当前经济版本为 `singleplayer-economy-v2`，内容版本为 `items-world-v1`。金额以十进制字符串保存，并使用 BigInt 计算。

- 修改经济配置时，同步 [V2 经济配置](../docs/GAME_ECONOMY_V2.json) 与 `dist/economy.json`，执行规则测试和经济校验。
- 修改运行资源时，更新 `dist/sw.js` 的缓存版本及必要的资源列表。
- 修改存档、经济或内容版本含义前，准备并验证已有存档的迁移方案。
- [开发文档](../docs/)中包含历史设计与阶段性验收记录，不应将旧物品数量、布局或测试数量当作当前状态。
