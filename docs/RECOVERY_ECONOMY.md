# 相邻容器回收保底

2026-10-14 生效。替代此前按分钟计算的恢复目标。

- 高一级开箱总物品售价低于费用时，记录两者差额，按容器等级独立保存。
- 返回紧邻低一级开箱，按「掉落总售价－本次费用」减少该差额。目标最多 7 次，硬上限 10 次。

- 以出售全部相关掉落为前提；保留收藏、升级仓库及其他额外消费不属于补足保证。不会直接赠送金币。
- 同档再次挑战会按新结果更新该档缺口；其他等级进度独立保留。存档刷新不会重置，旧存档无需清空。
