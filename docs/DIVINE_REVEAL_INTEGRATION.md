# 日冕揭示接入

正式入口：game/dist/index.html。7 级三段、EX 四段，EX 第三段额外蓄力，第四段才插入物品节点。

app.js 通过 divine-reveal.js 适配器复用 reveal-lab-gpu.js 的日冕方案。同一件物品切换阶段保留同一画布；下一件、结算、跳过及离开页面销毁画布和 GPU 资源。沿用原有音效、点击冷却、键盘操作与跳过逻辑。

背景为代码虹彩，EX 的六块彩云独立入场；符文白色，每步叠加一圈，最终取消抖动并保留旋转。最终白色圆点及菱形装饰保留。7 级没有彩云。物品移除炫彩描边。

离线缓存版本 v2.0.210，包含 Three.js 本地依赖、云图集及适配器。Three.js 许可证在 game/dist/vendor/three/LICENSE，参考来源在 reveal-lab-sources.md。

验证：node --test game/tests/*.test.mjs，79 项通过。隔离内存存档服务 game/tests/reveal-browser-server.mjs 支持指定端口；浏览器验证普通 6 级 → 7 级三段 → EX 四段 → 结算，第三段 EX 无物品节点，最终单画布，进入结算和 Escape 跳过后零画布，未出现渲染错误。验证未使用真实玩家存档。

## 单段揭示更新

7 级与 EX 均直接进入最终展示，取消逐段蓄力及额外推进点击。点击继续下一件的操作与普通品质一致，原有最终背景、符文与光环保留。预览播放、重播和时间轴同步改为单段，原蓄力光核对比隐藏。隔离浏览器验证普通 → 7 级 → EX 每次均直接出现对应物品，无渲染错误；缓存版本 v2.0.223。

## 首帧与切换性能修正

此前页面 CSS 黑底、切入后才动态加载和编译光效，且每件物品销毁并重建 GPU 上下文，导致黑帧及首次卡顿。现改为空闲预热完整材质、连续揭示复用画布、插入前绘制背景，尺寸未变时不重设渲染目标；离开揭示时停止绘制并移除画布，页面关闭时才销毁 GPU。加载期间使用深绯 CSS 背景兜底。82 项测试通过，含预热、先绘制后插入、复用上下文与过期加载取消测试；隔离流程验证 6 → 7 → EX 正常、无控制台错误。缓存 v2.0.225。
