# 网页 MVP 0.1 实现与验证记录

- 日期：2026-10-13
- 实现目录：`game/`
- 画风：用户指定的简单多边形；各等级不同颜色卡框和背景，EX 炫彩。
- 经济配置：与 `GAME_ECONOMY_V1.json` 一致。
- 运行方式：原生 ES Modules 静态网页，IndexedDB 存档，Service Worker 离线缓存；不需要安装框架依赖。

## 已完成范围

七种箱子、143 个物品、逐件及集中结算、经验解锁、新手阶段、奖励、仓库锁定与出售、图鉴、六格实物展柜、本地自动保存和备份、音效及减少动画、桌面和手机布局。

## 自动测试

`npm test`：15 项全部通过，覆盖数值内容对应、概率归一及加成边界、EX 权重和替换、固定数量、不可变交易、低资金/未解锁/冷却限制、下水道规则、重复结算与恢复、大整数、一次性奖励、301 次成长流程、展示占用与锁定、无效存档、48 位整数采样。

EX 与所有等级覆盖使用隔离的测试随机源，不更改生产概率。测试存档生成器在 `game/tests/make-fixture.mjs`，不会加载到发布应用。

## 实际浏览器检查

- 正常开启一档箱，3 件掉落，扣费 1,500。
- 保留第一件后刷新，恢复相同三件物品，第一件仍显示已保留。
- 将其他两件出售，实际到账 1,048，余额 2,548；保留的 627 价值物品没有计入现金。
- 仓库只持有保留的实物；图鉴保留 3 种发现。
- 锁定后出售按钮不可用；展示一件后，第二个展位无法再次选择唯一实物。
- 导出测试存档再导入，恢复余额、经验、图鉴和展示记录。
- 停止独立测试 HTTP 服务器，再刷新网页，仍能通过缓存加载游戏并恢复存档。
- 390px 手机视口检查开箱、收藏馆、底部导航与设置入口，无横向页面溢出。
- 图标按钮鼠标与键盘操作均验证；修复了 SVG 内部图形影响图标按钮点击的问题。
- 检查普通七级的不同边框和背景；三种 EX 均显示炫彩 SVG、背景和卡框。
- 浏览器检查过程中未发现应用控制台报错。
