# 游戏计划书 — 单机版 V1

- 更新日期：2026-10-13
- 当前范围：纯离线单机，先完成可玩循环与收藏体验。
- 目标平台：网页游戏，本地运行玩法与存档；网页 MVP 的建议范围与验收见 [网页 MVP 计划](WEB_GAME_MVP.md)。
- 网页 MVP 0.1 已实现于 `../game/`，采用简单多边形画风；实现及验证记录见 [MVP 验证记录](WEB_GAME_MVP_VERIFICATION.md)。
- 本轮用户授权：先不考虑联网，由 Codex 完成数值设计；新手爆率适当提高，快速度过成长期。
- 数值实施依据：[数值定稿](GAME_ECONOMY_V1.md) 与 [机器配置](GAME_ECONOMY_V1.json)。本版覆盖前版的待定概率、初版返还率目标和联网开发顺序。

## 1. 定位与核心循环

多元收藏世界，2D/3D 混合表现。核心循环为：封面 → 主页 → 开始寻宝 → 选择容器 → 点击容器开启 → 揭晓物品 → 点击任意位置关闭 → 回到当前容器的开启页面。神秘图鉴记录发现，收藏馆展示持有收藏。完整页面层级以 [网页计划第4节](WEB_GAME_MVP.md#4-页面与玩家流程) 为准。

一次操作只开启一个箱子；不采用批量开箱。没有购买钥匙的中间步骤。

## 2. 确定的开箱规则

| 箱子 | 价格 | 固定数量 | 普通物品等级 |
| --- | ---: | ---: | --- |
| 下水道 | 免费 | 1 | 1～4 |
| 1级 | 1,500 | 3 | 1～7 |
| 2级 | 6,000 | 4 | 1～7 |
| 3级 | 60,000 | 5 | 2～7 |
| 4级 | 700,000 | 6 | 3～7 |
| 5级 | 8,000,000 | 7 | 4～7 |
| 6级 | 90,000,000 | 8 | 5～7 |

下水道无每日或累计次数上限，无空掉落。1级普通产出常见，2、3级少见，4级极少见；全部箱子均可掉落 EX。普通等级和物品按配置独立有放回抽取，允许重复。

## 3. 普通物品与 EX

- 普通物品七级：1级三位数价值，每升一级增加一位，均价取对应整数区间中点。
- 每级使用 20 个固定价格位，共 140 个普通物品数值位；实际价格围绕均价集中分布，每个编号等概率，完整价格见 JSON。
- EX 三种，均价为7级普通物品平均价值的50倍，本版三个均定价27,499,999,975。
- 每件先独立判断 EX，命中后替换该件普通物品，总数量不变。三种 EX 条件权重2∶2∶1，同箱可多件、可重复。
- 下水道单件 EX 概率0.0010%；一至六级依次0.0020%、0.0022%、0.0024%、0.0026%、0.0028%、0.0030%。
- EX 的名称、美术、题材以及独立类别/特殊版本的表现方式待定，但产出与经济按独立特殊物品处理。

## 4. 成长与新手机制

- 初始货币3,000；出售100%标价到账，无手续费。
- 新存档前200次付费开箱，将最低普通等级的8个百分点概率移到下一等级；201～300次移4个百分点；301次恢复标准。
- 加成不影响 EX；下水道不消耗新手次数。展示加成阶段与剩余次数。
- 一至六级箱累计经验门槛为0、60、240、800、2,400、7,200。
- 下水道及一至六级每次经验为1、3、6、12、24、48、80。
- 二至六级解锁时一次性发放该箱三次开箱费用。奖励、经验与新手次数随事务保存，不能重复领取。
- 不设永久概率/售价增益、幸运值、保底或重复保护，避免叠加多套数值体系。
- 下水道最短周期2秒，付费箱3秒，结算操作另计。本版不加入自动开箱或离线收益。

## 5. 经济验证结论

六档标准期整箱亏损率约5%、21%、35%、50%、65%、75%，递增成立。普通返还率约115.34%、147.98%、126.27%、95.09%、92%、88%，取代旧版未验证的返还率建议。

EX 高价值会明显拉高完整期望，特别是低级箱；具体完整收益见数值文档。不得以普通负收益认定四、五级一定回收货币，也不得将 EX 期望当作新手常见收入。

低级箱提供资金恢复，高级箱提供更高收藏效率。原“亏损箱返还通常60%～85%”不再作为要求，实际亏损幅度及新手缓冲已在数值文档披露。

在关闭 EX、每付费箱含操作时间6秒的模型中，全部出售通常约26分钟解锁六级箱；每箱仅兑现80%价值通常约44分钟。具体分位数、抽样规模和限制见数值文档。解锁完成不等于收藏完成。

## 6. 仓库、图鉴与结算

- 仓库不设容量费用或上限，同物品堆叠。物品锁定后禁止普通一键出售。
- 图鉴在掉落事务完成时记录，出售后保留历史发现；当前持有量单独记录。
- 发现和集齐不额外发货币，避免未经验证的新增收入来源。
- 揭晓层展示本次全部产出；物品显示后，点击页面任意位置关闭并回到当前容器的开启页面，不要求先逐件选择保留或出售。关闭默认保留尚未处理的物品并入库，不自动出售；这是为闭合新流程采用的实现约定。出售在仓库进行，成本与估值不得显示为出售收入。
- 结果未处理时可恢复；扣费、发奖、经验、新手次数与解锁奖励必须一致保存，避免丢失和重复执行。
- 收藏馆展示需要持有对应实物；展示物品应锁定防误卖。展位布局、视觉形式与操作细节后续设计。

## 7. 单机存档

所有规则、掉落、仓库、经验、货币与图鉴本地执行和持久化。开箱结果提交后恢复同一结果，不重新随机。保存数值版本和一次性奖励状态。

账号、云存档、服务器验证、玩家交易、排行榜和联网参观全部移出当前版本。联网方案以后单独设计，当前不为其添加依赖。

## 8. 最小可玩版本

先实现全部七个开箱入口与数值配置、扣费和结果恢复、保留/出售、图鉴、经验解锁及新手阶段显示。以少量视觉素材填充已定义数值位，逐步补足主题内容；每个数值位保持独立物品编号。

目标平台已确定为网页。网页 MVP 已完成，后续按新页面层级改版；具体页面、交互和阶段验收见 [网页 MVP 计划](WEB_GAME_MVP.md)。美术方向为参考《荒野乱斗》的整体卡通表现，覆盖界面、角色、场景、图标与动效，使用原创素材。世界题材与后续3D模型范围仍需设计，这些不会由数值文档自动推断。

## 9. 验收

1. 数量、普通等级范围、EX替换和2∶2∶1权重正确。
2. 读取整数概率权重，不用展示用四舍五入百分比抽取。
3. 同级价格与权重符合配置；标准期亏损率逐档递增。
4. 新手200/201与300/301边界正确，奖励只能领取一次。
5. 扣费、发奖、经验和新手计数中断恢复一致。
6. 物品售价使用可靠整数计算，EX及累计资金不溢出。
7. 普通收益、含EX收益和实际现金收入分开统计。
8. 本地可独立运行，核心玩法无网络请求依赖。

数值已作为V1实施基线；原型测试发现节奏问题时按版本调整，并重新跑验证，不再将本轮已决定的概率和成长参数列为未决。
