# 网页游戏 MVP 内容计划

- 日期：2026-10-13
- 本轮目标：MVP 已实现，记录后续页面与美术改版计划；本轮仅更新文档，不开始编码或发布。
- 已确定：网页平台；沿用纯单机玩法与现有 V1 数值。
- 页面层级与寻宝交互已于 2026-10-13 由用户确定，以第4节为后续改版基线；既有实现记录不代表已完成本次改版。
- 数值依据：[游戏规则](GAME_SPEC.md)、[数值说明](GAME_ECONOMY_V1.md)、[机器配置](GAME_ECONOMY_V1.json)。本文不修改概率、价格或成长门槛。

## 1. MVP 要验证什么

玩家打开网页后，能理解规则、开出物品，在出售换钱和保留收藏之间做选择，逐步解锁更高级箱子，并在下次打开时继续游玩。

首版重点验证三个问题：开箱反馈是否有趣，成长过程中是否愿意继续，收藏是否能形成目标。解锁六级箱是成长阶段目标；集齐普通物品、收集 EX 和布置展柜是后续收藏目标，不要求首轮试玩集齐。

## 2. 平台与表现范围

| 项目 | 首版范围 |
| --- | --- |
| 运行方式 | 浏览器网页，静态部署，本地运行游戏逻辑 |
| 优先设备 | 桌面浏览器；同时支持手机竖屏基本游玩和触摸操作 |
| 界面 | 中文、2D 卡片与面板、简单开箱和稀有掉落动画 |
| 存档 | 一个本地存档，自动保存，支持导出和导入 |
| 网络 | 首次加载获取网页资源；核心游玩和存档不调用游戏服务器 |
| 离线 | 完成首次加载并缓存资源后，支持断网重新打开；首次断网访问不作为要求 |
| 收藏馆 | 一个固定布局的 2D 展柜，建议 6 个展位 |

网页平台与单机模式并不冲突。账号、云存档和多人功能继续留到后续。原计划中的 3D 核心场景保留为后续表现目标，不进入 MVP 验收。

## 3. 必须做的玩法

### 3.1 开箱与成长

- 下水道和一至六级付费箱共 7 个入口，执行现有价格、数量和掉落规则。
- 初始货币 3,000；下水道免费且无次数上限，资金不足时始终有恢复路径。
- 每次只开一个箱子，直接扣游戏币；没有钥匙、批量或自动开箱。
- 展示箱价、产出件数、普通等级范围和 EX 概率，规则页提供完整概率说明。
- 展示经验、下一档解锁进度、新手加成阶段及剩余次数；解锁时提示一次性货币奖励。
- 下水道最短间隔 2 秒、付费箱 3 秒；减少或跳过动画仍遵守最低间隔。
- 资金不足、档位未解锁、开箱进行中和结果未处理时，按钮有明确状态和原因。

### 3.2 结果处理

- 展示全部掉落，标明等级、售价、首次发现、重复和 EX。
- 明确区分本次成本、总估值、出售到账与保留数量。尚未出售的估值不显示为已到账收益。
- 物品显示后，点击页面任意位置关闭揭晓层，回到当前容器的开启页面。
- 为闭合该交互，默认约定关闭时将本次尚未处理的掉落全部保留入库，不自动出售；重复物品按实际件数入库。出售与批量处理放在仓库，不作为关闭揭晓层的前置步骤。
- EX 出售前需确认价值和名称，避免仓库快捷操作误售稀有收藏。
- 入库事务完成后才能再次开箱；中断后恢复同一未完成结果，不重新抽取，不重复入库。

### 3.3 仓库和图鉴

2026-10-14出售功能：仓库左下进入出售模式，点击独立物品勾选/取消；按选定品质及以下一键勾选，范围1～7级。显示件数和总价值，确认后同事务售出；EX手动出售在确认中标明。被锁定、展出的物品不可批选出售，其他物品保留各自位置。仓库另设自动出售选项，默认关闭，整数阈值本地保存；之后开箱时严格低于阈值的单件掉落直接按售价入账，等于阈值保留，锁定/展出的同类物品保留。EX也按用户设置的价值阈值判断。自动售出物品仍记录发现、仍参加揭晓，关闭结果不重复售出或入库。

图鉴载体更新：展开空白双页书，沿用卡通粗描边、棕色封面与金色护角。当前每跨页12项、左右各6项，共12个跨页；支持发现进度、未知剪影、翻页与已发现物品详情，左上返回、右上金币。载体贴图与动态内容分层渲染。

仓库交互参考（用户于2026-10-13提供）：https://df.lza11111.com/game ，三角洲行动理包模拟器。参考其物品占格与自由拖动的方向；保留本项目已确定的深蓝背景、白色半透明格子、极简导航和卡通美术。当前仅取得网站介绍，实际页面加载超时，尚未核验其具体拖动、旋转及碰撞反馈，不能将这些细节视为用户已确认的需求。

2026-10-13 仓库改版定稿（覆盖下方旧MVP布局与堆叠方案）：初始20列×10排，半透明白色格线、透明度更低的白色格底。仅显示左上返回、右上金币和右下升级仓库。每件物品独立占据固定矩形区域（1、2、3、4、6格等），同类不堆叠；支持鼠标/触摸拖动，整格吸附，禁止重叠和越界，保存各件位置。每次升级增加3排（60格），首次1,500金币，后续每次翻倍；扣费与容量同事务保存。容量不足的已有/新获得物品保留在待整理区，扩容后自动摆入，不销毁物品。旧存档按数量展开，不改变总数和价值。

- 仓库显示已保留物品，同编号堆叠，无容量费用或上限。
- 支持按等级筛选、按价值排序、查看详情、出售指定数量和锁定物品。
- 批量出售只处理未锁定物品，并展示件数和总到账额。
- 图鉴包含 140 个普通物品和 3 个 EX，共 143 个独立编号；显示总进度、分级进度、发现状态和当前持有量。
- 未发现物品显示剪影或未知卡片；已发现物品即使全部出售，也保留发现记录。
- 图鉴没有额外货币奖励、属性增益或强制收集任务。

### 3.4 简化收藏馆

2026-10-14页面定稿：深蓝背景上仅显示六个魔法展台和左上退出按钮。藏品叠加在展台上，主页面不显示金币、标题、说明或其他导航。点击展台选择/替换藏品，撤下当前藏品在弹出面板中操作。

- 一个 2D 固定展柜，建议 6 个展位；可放入、替换和撤下已持有物品。
- 每个展位占用一件实物，同一件不能重复占位；持有多件时可摆放多个。
- 展示物品不可出售。撤下后恢复为仓库可用数量，玩家主动设置的锁定继续有效。
- 展柜保存并恢复，显示物品名称、等级和收藏价值。
- 首版不做房间扩建、家具、自由移动、装修或联网参观。

### 3.5 存档和设置

- 自动保存货币、经验、已领解锁奖励、新手计数、固定掉落结果、仓库、图鉴和展位。
- 导出存档文件；导入前校验版本、物品编号、数量与金额，展示概要并确认替换当前进度。
- 导入保留文件中的历史状态，不重抽未处理掉落、不重发奖励。单机备份允许回退到导出的时间点，不宣称提供防回档或防修改能力。
- 提供音效开关、减少动画和重置存档；重置明确提示将删除当前进度并要求确认。
- 存档基于浏览器与网站地址，不自动跨设备同步；设置页说明清除网站数据会清除进度，并提供备份入口。
- 保存失败时停止后续开箱和出售，保留当前可恢复状态并提示重试；不能显示虚假的“保存成功”。

## 4. 页面与玩家流程

本节为用户于 2026-10-13 确定的页面层级，替代旧版同屏选箱方案。

### 4.1 页面层级与布局

| 页面或展示层 | 主要内容与布局 | 进入及后续操作 |
| --- | --- | --- |
| 封面 | 游戏封面与进入游戏按钮 | 点击按钮进入主页 |
| 主页 | 右上角显示金币数量；右下角放置主要操作“开始寻宝”；右侧设置侧边栏 | 开始寻宝进入容器选择页；侧边栏按仓库、图鉴、收藏馆排列，分别进入对应页面 |
| 容器选择页 | 容器以横向轮播形式展示，覆盖既有7种容器；保留价格、解锁状态与必要规则信息 | 横向切换浏览，点击对应可用容器进入该容器的开启页面；选中容器本身不扣费 |
| 开启容器页 | 选中的容器位于画面中央，持续播放待机动画，参考《荒野乱斗》宝箱的动态表现 | 点击容器触发一次开启，随后弹出揭晓动画 |
| 揭晓层 | 先播放揭晓动画，随后显示本次获得的物品；同次多件产出必须完整展示 | 物品显示后，点击页面任意位置关闭，回到同一容器的开启页面 |
| 仓库 | 持有物品、数量、等级、售价与锁定状态 | 查看、锁定、出售和批量处理 |
| 图鉴 | 143个编号、发现进度、分级筛选 | 查看已发现和未知物品 |
| 收藏馆 | 固定展柜与展位 | 摆放、替换、撤下收藏 |

主流程：**封面 → 主页 → 开始寻宝 → 容器选择（横向轮播）→ 开启容器（中央待机动画）→ 点击容器 → 揭晓动画 → 显示物品 → 点击任意位置关闭 → 回到开启容器页**。

关闭揭晓层后保持当前选中的容器，不返回主页或容器选择页，也不自动开启下一次。返回导航作为配套实现：开启容器页可返回容器选择页；容器选择页及仓库、图鉴、收藏馆可返回主页。

### 4.2 动画、点击与结果保存

2026-10-14开箱操作更新：取消所有固定开箱冷却，结果结算后可以立即再次开启。开启请求保存及揭晓期间仍禁止重复触发，连点或长按空格不重复扣费、不重启动画。空格/Enter在选择页进入中央容器、开启页触发开箱、物品展示页关闭结果；输入框或弹窗中不拦截这些键。保留短暂揭晓演出，覆盖旧版2秒/3秒最短周期要求。

- 容器轮播各项下方显示开启费用；余额足够为白色，不足为灰色。余额不足时点击容器提示“金币不足”，停留在选择页，不扣费、不进入开启页。

- 容器待机应有持续的生命感，可通过晃动、弹跳或挤压伸展实现；具体动作以美术样板确认，不能只用静态卡片代替。
- 状态顺序固定为：容器待机 → 开启与揭晓动画 → 物品展示 → 关闭揭晓层 → 容器待机。
- 点击容器时校验金币、解锁条件与最短开箱周期；成功提交扣费与固定掉落结果后再播放动画。动画和结果展示期间不能再次触发开箱。
- “点击任意位置关闭”只在物品展示阶段生效；开启点击不能穿透到揭晓层，关闭点击不能穿透并再次开启容器。
- 关闭时默认保留尚未处理的全部物品，完成一次入库事务后返回待机；保存失败则保留结果并提示重试。该默认保留行为是配套实现约定，用户明确指定的核心行为是任意位置关闭并返回开启容器页。
- 刷新或意外关闭后恢复固定结果或已完成的入库状态，不重复扣费、抽奖、入库或发放成长奖励。
- 减少动画设置可缩短演出，但仍保留揭晓与物品展示两个阶段，并遵守既有最短开箱周期；为关闭操作提供键盘等效入口。

设置、规则和存档管理使用辅助弹窗或面板，不增加到指定的三个右侧边栏入口中。手机端适配横向轮播与触摸操作，确保右上金币、右侧导航和右下开始寻宝按钮可见且不互相遮挡。首次引导跟随上述流程，不赠送额外货币、不强制特殊掉落。

### 4.3 整体美术方向

2026-10-13 页面精简定稿：二级容器选择页仅显示横向容器轮播、中央高亮容器上方名称、右上金币和左上退出；文字粗体黑描边。第5级“星界封箱”改为“皇室珍藏”，第6级“远古方舟”改为“星界遗物”。点击中央选中的可用容器进入三级开启页，仅显示持续跳动的容器；点击开启后容器消失，产出仅展示贴图与光效。物品展示后点击任意位置全部保留并回到容器选择页，保持当前容器居中。现阶段物品使用MVP图形素材，后续补正式贴图。

整体参考《荒野乱斗》的高饱和卡通风格，范围包含界面、角色、场景、图标、容器与动效，采用原创角色和素材。先制作一张包含场景、容器及实际界面元素的核心页面美术样板，确认比例、描边、色彩、字体与光影后再推广；具体题材、角色设定与资产清单另行细化。本轮不将美术目标视为已经实现。

## 6. 明确移出 MVP 的内容

- 账号、云存档、服务器经济验证、排行榜、玩家交易和联网参观。
- 3D 场景、自由漫游、角色控制、复杂物理和镜头系统。
- 战斗、剧情任务、合成、强化、装备属性和多套养成系统。
- 每日任务、体力、保底、幸运值、永久概率增益、自动开箱和离线收益。
- 真实货币付费、充值、广告和付费开箱。
- 多存档槽、跨设备同步、多语言和安装式应用商店发布。

## 7. 技术建议

首版建议 React + TypeScript + Vite，界面与动画使用 HTML/CSS，IndexedDB 保存本地状态，Service Worker 缓存离线资源。MVP 无需 3D 引擎、后端服务或账号数据库。具体依赖版本在开始实现时确认。

- 游戏规则独立于界面，直接读取 V1 JSON；物品命名和素材另放内容配置。
- 货币与售价使用 BigInt，存档序列化为十进制字符串；经验与概率权重采用经过范围检查的整数。
- 随机抽取保持整数权重，使用无偏整数采样；不把页面四舍五入后的百分比用于计算。
- 存档包含 schemaVersion、economyVersion 和 contentVersion；兼容迁移不重算历史物品价值。
- 开箱在同一存档事务中提交扣费、固定结果、图鉴发现、经验、新手计数与奖励标志，之后播放动画。
- 掉落先进入待处理结果；选择保留或出售后，以事务转入仓库或货币。每条掉落有唯一编号和处理状态，重复点击只生效一次。
- 使用一个活动存档写入者；同一浏览器打开第二个游戏标签页时提示回到原标签，避免覆盖进度。
- 显示完整整数金额，并可补充万/亿缩写；交易确认使用完整金额。

按此顺序推进，每个阶段都留下可运行版本。暂不估算固定工期，待 A 阶段确定代码基础、实际界面工作量和素材方向后再排期。

## 9. MVP 验收标准

1. 新存档初始货币为 3,000；全部 7 个入口与 V1 的价格、数量、等级范围、EX 替换规则一致。
2. 新手第 200/201、300/301 次边界正确；免费箱不消耗加成次数，解锁奖励每档仅发一次。
3. 开箱、处理单件、批量出售中反复点击或刷新，不重复扣费、发奖、入库或售出；恢复相同待处理结果。
4. 大金额计算精确，包括 EX、多件出售与持续累计；余额不足不可扣成负数。
5. 143 个物品编号可被发现与持有；关闭揭晓层时全部未处理物品准确入库，同箱重复件数正确，出售不清除发现记录。
6. 锁定物品不会被批量出售；展位占用实物、撤下释放数量，展示和出售不会重复消耗同一件。
7. 刷新、关闭重开、导出再导入均恢复对应状态；损坏或不兼容存档不能覆盖有效存档。
8. 桌面与约 390px 宽手机视口可完成开箱、处理结果、锁定、出售和摆放，无关键按钮被遮挡；键盘可访问主要操作。
9. 缓存完成后断网重新打开可以继续游玩；音效关闭与减少动画有效，跳过演出不缩短最短开箱间隔。
10. 实际试玩记录到二级箱、六级箱的耗时、资金不足次数和保留策略。既有模拟约 26～44 分钟解锁六级箱仅作比较基线，不当作用户必达时限。
11. 封面按钮进入主页；主页金币在右上、开始寻宝在右下，右侧边栏依次为仓库、图鉴、收藏馆。
12. 开始寻宝进入横向轮播容器选择页；点击可用容器进入中央展示容器的开启页，选择过程不扣费。
13. 容器有待机动画；点击后先揭晓动画再显示全部物品，物品显示后任意位置点击可关闭并回到当前容器；快速连点不穿透、不重复开箱。

EX 极稀有，验收通过隔离的测试随机源覆盖其流程，不等待自然抽中，也不改变正常存档的生产概率。优先测试交易状态与随机规则，再进行完整试玩。

## 10. MVP 完成后如何决定下一步

先观察玩家是否愿意继续开箱、是否主动保留与摆放物品、是否因资金恢复或结算操作而频繁中断。试玩记录由本地统计或人工记录取得，MVP 不依赖外部分析服务。

如果核心循环有吸引力，再补充更完整的主题素材和 3D 展示；如果成长或资金恢复导致明显重复劳动，先调整节奏并版本化重跑经济验证。联网与商业化作为独立后续规划。
