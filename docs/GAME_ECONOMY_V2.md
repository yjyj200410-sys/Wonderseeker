# 开箱盈利数值 V2

2026-10-14 生效，当前游戏读取 `game/dist/economy.json`，对应 `GAME_ECONOMY_V2.json`。当前平衡修订为 `expanded-drop-range-v1`。V1 及最初 V2 的验证报告保留为历史记录。

以当前每级 1 件普通物品、全部按标价出售为收益依据。秘境匣子至星界遗物的普通范围向低一级扩展，新加入档位的原始单件普通抽取概率均为 10%。下水道保持 1～4 级，街角木箱和旧城铁箱原本已包含 1～7 级。箱价、物品售价、件数、EX 概率和经验奖励不变。

1～3 级确保总售价严格高于费用；秘境匣子会在低价值组合时逐级提升普通掉落，保证最低净收益 2,205。4～6 级仍允许亏损，但盈利概率保持或提高。以下概率为第 301 次起的标准阶段，包含固定售价及开箱保底，不依赖新手加成、解锁奖励或从更高级箱子带来的回收记录。

新增档位从原有主要低档中分配权重；失落宝箱和皇室珍藏的高价值总权重保持 22%、20%。星界遗物的 6 级物品概率从 17% 提至 18%，以补偿新增低级物品，7 级仍为 3%。高级箱的盈利概率前两档保持原值，最高档从 83.62% 提升至 85.19%。星界遗物每箱至少出现 1 件 EX 的概率仍约 2.37%。

新手加成明确从原有主要档位向高一级转移 8 / 4 个百分点，避免新增低档吸收加成后无法提高盈利概率。高级箱前 200 次的盈利概率约为 88.26%、90.04%、93.69%。表中的抽取范围均可以在最终结果中出现；低级箱盈利保底可能提升部分低价值组合，秘境匣子标准阶段约 12.13% 的无 EX 开箱会触发提升，因此原始 10% 不等于最终低级物品占比。

经验门槛、一次性奖励保持原金额。奖励不再等于新箱价的三倍。回收保底继续使用真实掉落售价与成本差额，不直接赠送金币。新增低档使高级箱的极端单次亏损金额增大，但盈利频率保持或提高；相邻低级箱的回收目标仍为最多 7 次。保留藏品、升级仓库会消耗可用资金，盈利保证以出售全部掉落为前提。

V1 存档自动迁移到 `singleplayer-economy-v2`，保留金币、收藏、经验、锁定、展位、仓库升级、待处理结果及回收记录。存档保存 V1 已开次数，历史支出仍按旧价格核算，之后按新价格计费；旧待处理开箱保留原费用。读取和导入均先验证旧数据，迁移不会清空存档或调整余额。

此次仅改变未来抽取规则和低级箱保底，所有存档会计、售价、数量及成长字段含义不变；V2 存档继续直接兼容，旧待处理结果不重抽、不补发，不需要重置。

验证：`cd game; npm test`，40 项通过。`node docs/verify_economy_v2.mjs --write` 枚举掉落组合并调用部署引擎，准确计入盈利与入场保底；另每档连续开箱 20,000 次，共 140,000 次。关闭 EX、新手加成和解锁奖励后，各档仍累计盈利，1～3 级没有一次亏损。当前精确概率、期望与模拟见 `GAME_ECONOMY_RANGE_VALIDATION.json`；最初 V2 的旧报告不代表本次扩展。强制每次最低掉落时，4～6 级均在 7 次相邻低级开箱内补足。另验证了新增等级确实可出、加成阶段排序、V1 迁移及旧 V2 待处理结果兼容。
